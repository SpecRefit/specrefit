# SpecRefit 0.1.0

The first versioned SpecRefit release brings local OpenAPI inspection, targeted transformations and reviewed export to the browser and desktop. Contract processing stays on your machine, without accounts, telemetry or a processing server.

## Included

- Import YAML/JSON contracts and reference files; browse and search operations, parameters, request bodies, responses, security and schemas.
- Select one or more media types, extract inline schemas into explicitly named shared models and bundle external references into one document within the documented support boundaries.
- Preview changes and export the reviewed files. Browser exports use a ZIP for multiple files; desktop exports write to the chosen folder with source-file protection.
- Follow the system theme or switch between light and dark.
- Portable desktop packages with a bundled Electron runtime for Windows x64, macOS Apple Silicon/Intel and Linux x64, plus browser assets, a manifest and SHA-256 checksums.

## Downloads

Extract the entire desktop archive, then launch `SpecRefit.exe` on Windows, `SpecRefit.app` on macOS or `SpecRefit` on Linux. No separate Node.js or Electron installation is needed. Linux requires a graphical session and Chromium system libraries. The web archive contains static browser assets for hosting; it is not the Windows application.

Windows packages are unsigned. macOS packages use ad-hoc signatures without Developer ID or notarization; downloaded apps may be blocked by OS security policy. Native CI tests startup and export from the extracted packages, but full clean-machine and browser-download quarantine acceptance remain open. Native installers are not included.

## Scope of this first release

Representative OpenAPI 3.0.4, 3.1.2 and 3.2.0 fixtures are covered; SpecRefit is not a complete OpenAPI or JSON Schema validator. Broader reference/dialect semantics, project configuration persistence, contract comparison, CLI and Maven integration remain planned. Consult the repository's support documentation before relying on unsupported constructs. This 0.x release does not imply completion of the full product roadmap or a compatibility guarantee for future versions.
